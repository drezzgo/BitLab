APLICACIÓN DESDE GIT BASH

1. Crea una rama:

   git switch -c feat/extended-word-size-v1

2. Extrae el overlay en la raíz del repositorio:

   powershell.exe -NoProfile -Command "Expand-Archive -Path 'S:\Downloads\bitlab-extended-word-size-v1.zip' -DestinationPath '.' -Force"

3. Aplica las sustituciones de UI/documentación:

   powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./APPLY_EXTENDED_V1.ps1

4. Revisa:

   git status
   git diff --check
   git diff -- src/core src/components/react/WordSizeComparator.tsx

5. Valida:

   pnpm test
   pnpm build

6. Prueba manualmente:
   - N = 4096, 8192, 16384, 32768;
   - preset "Reto ×2";
   - N = 65535;
   - intentar 65536 debe ser rechazado;
   - codificar Huffman y RAW;
   - recuperar el archivo y verificar SHA-256.
