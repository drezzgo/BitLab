# Auditoría de cálculos

Las tarjetas expandibles explican los resultados mostrados por la herramienta sin intervenir en el motor matemático.

## Cálculos

- Bits originales = bytes del archivo × 8.
- Palabras = techo(bits originales / tamaño de palabra).
- Padding = palabras × tamaño de palabra − bits originales.
- Tamaño del contenedor = header fijo + nombre UTF-8 + MIME UTF-8 + metadata del codec + payload.

Blendy se utiliza únicamente para animar la transición entre la tarjeta compacta y su detalle expandido.
